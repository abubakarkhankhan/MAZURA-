MAZURA — RECIPE BOOK COMPLETE SPRITE PACK

This pack contains individually cropped PNG sprites:
- 20 individual gameplay/category/resource/item icons.
- 9 separate book UI elements (book, arrows, list rows, close button).
- Full UI and asset-sheet references.

Transparent PNGs:
Each sprite has been isolated from its generated source sheet with foreground
segmentation and saved as an RGBA PNG. Some very fine dark edge details may be
slightly softened because the source was a rendered image rather than layered
source artwork.

Unity import:
1. Extract this ZIP.
2. Copy the PNGs into Assets/UI/RecipeBook/Sprites.
3. Select all sprites in Unity and set Texture Type = Sprite (2D and UI).
4. Enable Alpha Is Transparency.
5. Set Sprite Mode = Single.
6. Use TextMeshPro for all recipe labels and counts so text remains editable.
7. Use 9-slicing only for suitable frame/button sprites after checking borders.

The full-screen image is a visual reference, not a working Canvas prefab.
